# Platform Metadata & Validation Logic

This document guides the architect and developers in implementing validation logic for content generated by the AI Content Factory.

| Platform | Character Limit | Recommended Hashtags | Media Requirements | Specific Constraints |
| :--- | :--- | :--- | :--- | :--- |
| **TikTok** | 4,000 (Caption) | 3-5 | 9:16 Video (Script only for MVP) | Captions should be punchy; first line is the "title". |
| **X (Twitter)**| 280 (per Tweet) | 1-2 | Image/Video (optional) | Threads should be limited to 10 tweets max for readability. |
| **LinkedIn** | 3,000 | 3-5 | Image/Document (Carousel) | Avoid "corporate speak". Use line breaks every 2-3 sentences. |
| **Reddit** | 40,000 | 0 | Text-only (mostly) | Titles must be < 300 chars. Content must provide value, not just a link. |
| **YouTube** | 5,000 (Desc) | 3 | 16:9 Video (Script/Outline for MVP) | Titles should be < 70 chars for SEO. |

## Validation Rules (Logic for Architect)

1. **X (Twitter) Thread Validation:**
   - Ensure every element in the `tweets` array is <= 280 characters.
   - If `content_type` is 'single_tweet', the array must have exactly 1 element.

2. **LinkedIn Content:**
   - `post_body` should be checked for "too many hashtags" (limit to 5).
   - If `carousel` is provided, each `slide_content` should be concise (< 200 chars).

3. **Reddit Safety:**
   - Strip any "link shorteners" (e.g., bit.ly) as they often trigger spam filters.
   - Ensure a `tl;dr` exists if the body is > 1000 characters.

4. **General AI Output:**
   - Must be valid JSON matching the `prompt-schemas.json`.
   - Brand voice consistency: Check for presence of "forbidden" words if using 'Professional' preset (e.g., "yeet", "pog").
